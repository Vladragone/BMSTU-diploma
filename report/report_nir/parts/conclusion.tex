\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

Цель данной научно-исследовательской работы была достигнута - проведён сравнительный анализ методов предотвращения рассинхронизации в многопользовательских игровых приложениях.

Для достижения поставленной цели были выполнены следующие задачи:

\begin{enumerate}
\item проведён анализ предметной области синхронизации игровых состояний и передачи данных в многопользовательских играх;
\item формализована задача обеспечения согласованности игровых данных между клиентами и сервером;
\item рассмотрены существующие подходы к синхронизации состояния;
\item рассмотрены методы передачи игровых данных;
\item описаны типовые игровые данные, подлежащие хранению, обновлению и передаче;
\item определены основные причины возникновения рассинхронизации;
\item сформулированы критерии для оценки и сравнения методов синхронизации;
\item проведён сравнительный анализ методов предотвращения рассинхронизации на основе сформулированных критериев.
\end{enumerate}
